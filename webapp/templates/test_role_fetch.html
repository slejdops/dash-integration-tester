Troubleshooting Guide

Common Issues:

HTTP 401 Unauthorized:
  • LTPA token has expired (default: 120 minutes)
  • Token signature validation failed
  • Clock skew between client and server
HTTP 403 Forbidden:
  • User lacks required role for endpoint
  • Security constraint configured on endpoint
HTTP 404 Not Found:
  • Endpoint path is incorrect
  • Application not deployed or not started
Connection/SSL Errors:
  • DASH server unreachable
  • Certificate validation failure
  • Firewall blocking connection
