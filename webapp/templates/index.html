About This Tool

This web application allows you to interactively test LTPA token authentication with DASH/WebSphere.

Features:

  • Acquire LTPA tokens by logging into DASH
  • View and inspect token details
  • Test role-fetching endpoints (simulating TCE integration)
  • Run mini stress tests to reproduce intermittent failures
  • Inspect request/response details for debugging

Use Cases:

  • Validate LTPA token acquisition and propagation
  • Test DASH endpoints with real LTPA tokens
  • Debug cookie domain/path issues
  • Reproduce intermittent authentication failures
  • Verify SSO configuration changes
